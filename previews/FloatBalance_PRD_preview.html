Milestone建议顺序
PRD 冻结 → 最小窗口原型 → 账户 / 轮询 → 错误球 → CSS / 告警 / 托盘 → 代理服务。
验收第一版
启动快、常驻稳、余额清晰、断网有缓存、自定义样式可恢复。
